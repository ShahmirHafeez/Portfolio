# Shahmir Hafeez — Portfolio Website

A responsive dark portfolio made with plain HTML, CSS, and JavaScript.

## Run in VS Code
1. Extract `shahmir-portfolio.zip`.
2. Open the `shahmir-portfolio` folder in Visual Studio Code.
3. Open `index.html`.
4. Either double-click `index.html` to open it in a browser, or install the **Live Server** extension in VS Code.
5. If using Live Server, right-click `index.html` and choose **Open with Live Server**.

## Customize before publishing
- Search for `Shahmir Hafeez` and edit your name if needed.
- Replace `your.email@example.com` with your actual email everywhere it appears.
- Replace the GitHub and LinkedIn sample links with your own profile URLs.
- Update project names, descriptions, tech stacks, and GitHub links to match work you have actually completed.
- Remove skills you are not comfortable discussing yet.
- The contact form uses `mailto:`: it opens an email draft but does not send/store messages through a backend.

## Deploy
You can publish this static website with GitHub Pages. Create a GitHub repository, upload `index.html`, then enable Pages in the repository's Settings. You can also host the file as a static site on AWS S3 (with static website hosting configured).
